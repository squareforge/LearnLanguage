# LearnLanguage review 修复记录 · 2026-10-26

本轮在已有的统一学习项、星荣课程和透明浮窗实现上，处理 review 中的数据可靠性、练习衔接和设置兼容问题。代码保留在当前工作区，未提交或推送。没有使用现有学习数据库执行恢复或迁移测试。

## 已完成

- 每日队列按当前词库、当地日期和每日目标构建；切换词库不会被其他词库的复习记录阻挡。跨天与电脑唤醒刷新任务；重新加载会扣除当天已学新词，主动“再学一组”单独处理。
- 学习反馈、词库已学数量、历史明细和打字统计在同一 WCDB 事务中提交。提交失败保留当前题目及输入，显示错误，可直接重试。清理了重复的旧复习更新规则。
- 修正 WCDB 自增模型的生成主键回填，使新建词库、词项及学习记录获得真实 ID。
- 导出使用 SQLite 快照与 MMKV 官方备份，归档带必需文件清单和 SHA-256 校验。解析拒绝越界长度、未知或重复文件、目录穿越和尾随数据，保留旧版归档读取能力。
- 恢复先在临时目录解密、校验、迁移并准备数据库，再暂停练习和朗读，关闭存储并替换文件。替换带恢复日志，失败回滚，启动时恢复未提交的替换；恢复后重新打开存储并清除旧队列、课程会话和例句缓存。
- 内置词库升级使用独立来源 ID 到本地 ID 的映射；旧安装按唯一词库名和分类名建立映射。同步缺失词库、新增单词、释义、音标和例句，保留已有词 ID 与学习进度。版本写入与内容一起提交，失败可重试。
- 初始数据库从忽略规则中排除，清除误跟踪的 db-shm；增加词库 manifest、校验脚本和 Xcode 构建检查。更新词库时必须同步资源和 manifest。
- 设置在读写边界集中校验。非法每日数量不再传给 prefix；透明度、字体、语速、音量和时间间隔采用有效范围。
- 统一练习面板接入显示释义、逐字母/整词占位、跟播字母、听写和错误次数自动提示。听写设置修改可作用于当前会话；“从不自动提示”保留原语义。
- 本地发音使用实际语速设置，设置页恢复语速选择；本地和共享 TTS 按具体 utterance 管理完成状态，旧播放的取消事件不能清除新播放回调。
- 翻译按独立请求保存窗口与回调，支持取消；查词和浮窗忽略旧请求结果。OCR 迟到、关闭窗口和语言方向变化会使旧请求失效；错误结果不能存入生词本。
- 修正浮动翻译错误的展示链路，macOS 15 以下显示系统版本要求。文档与部署目标统一为 macOS 13.5+，开发需要含 Translation SDK 的 Xcode 16+。
- 复习记录提供上一页/下一页，在 SQL 中分页和稳定排序；每页批量取词，避免每行反复加载整本词库。
- 数据库维护执行实际 SQLite quick_check / integrity_check；修复入口强制内容合并并报告失败，成功后刷新学习上下文。
